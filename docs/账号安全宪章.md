# 账号安全宪章

状态：生效  
日期：2026-08-27

## 最高原则

账号与数据安全高于通关率、性能、自动化程度、开发速度和使用便利性。无法确认时必须停止或退回观察模式。

## 不可违反的边界

- 不读取或修改游戏内存、封包和文件；
- 不注入、Hook、隐藏或绕过反作弊；
- 不保存游戏账号密码、验证码或导出 Cookie；
- 不自动执行付费、抽卡或受保护资源消耗；
- 大模型不能直接获得输入能力；
- 战斗方案执行前必须有一次性人工审查授权；
- 未达到最低通关标准时不执行；
- 游戏版本、账号、快照、关卡、计划或授权不一致时不执行；
- 未知页面、错误窗口、低置信度和紧急停止状态下不执行；
- 当前阶段不提供真实系统输入后端。

## Go/No-Go

任一安全测试失败、官方规则变化、游戏版本变化或出现无法解释的安全事件，执行能力均视为 No-Go。即使用户要求继续，也不能绕过安全内核。
