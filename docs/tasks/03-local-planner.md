## 目标与所有权

交付 `packages/starhelp-planner/`（导入名 `starhelp_planner`）和 `docs/handoffs/local-planner.md`，提供纯本地 `analyze(request) -> result`。输入为当前私有快照、公共完整包、任务目标、硬限制及可选当前任务反馈；输出为可解释的方案/缺口及引用。

组件不访问网络、GUI、游戏输入或持久账号存储。读取/授权/加密/报告保存归B，公共资料与批准发布归A；旧 `abyss_ai` 仅阅读借鉴，不直接改写。

1. M0：确认有限条件、面板上下文/单位、三态、硬软要求、变体完整性和错误语义；真实关卡/实体由公共包提供，不把合成ID当真实资料。
2. M1/M2：独立包、纯函数接口、公共包/快照校验、版本一致、基本完整变体匹配、结构化结果；以合成包和档案验证闭环。
3. M3：适配部分/冲突/过期字段与角色所有权，装备实例身份及不可确定状态，缺失不填零。
4. M4：当前配装优先、遵守角色固定/排除与装备锁定的调装、玩法分区联合资源占用、完整替代组合、条件/证据/调整成本排序。
5. M4/M5：角色/光锥/行迹/遗器培养差距；材料表和字段完整适用时计算成本，库存不全不算净缺口；审核排障反馈，完整引用和生成版本供B形成报告。
6. M5/M6：对三模式固定样本、发布当期包和客户端能力做契约核验；提供构建产物/本地运行说明与验证证据，支持B黑盒联调。

## 必须通过的案例

| 案例 | 期望 |
|---|---|
| 完整主方案/完整审核替代 | 输出真实适用变体及关联条件/步骤，非任意拼队 |
| 多处替代只有独立批准 | 拒绝未经整队批准的组合 |
| 角色未知/确认未拥有 | 不进入确认拥有主方案；未知仅待确认候选 |
| 固定/排除/装备锁定冲突 | 无可行结果和冲突原因，不放宽硬限制 |
| 两队共享同一实例/身份歧义 | 排除冲突调装；身份未知不强行分配 |
| 缺失/过期/冲突字段 | 三态和依据显示，不当达标或补零 |
| 不同周期/版本、未知schema、证据禁用 | 不混用、不默认执行，返回覆盖/兼容缺口 |
| 无适用审核模板 | 公共资料引用与缺口，不生成个性化队伍 |
| 计算材料完整/不完整 | 完整适用才计算，相应缺项则明确未计算 |
| 实战反馈无规则支持 | 说明无法判断，不自动学习阈值或改公共模板 |

结果包括任务范围、当前/调装类别、完整变体、装备映射或缺口、条件满足状态、依据/缺项/不确定性、打法与培养优先级、证据及发布/模板/规则版本。证据状态与本地满足状态分开，排序分不是通关概率。
