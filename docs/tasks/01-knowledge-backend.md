## 目标与所有权

交付独立运行的 `packages/starhelp-knowledge/`（导入名 `starhelp_knowledge`），以及 `docs/handoffs/knowledge-backend.md`。本线程实现公共知识服务，不接收私有账号字段、派生特征、失败反馈或私有报告。

## 按依赖推进

1. M0：核对来源能力、许可与覆盖，提出所需公共字段和版本规则，按契约初稿报告待冻结内容。真实来源未验证不能标接入成功。
2. M1：独立包/配置、SQLite迁移、来源/实体/关卡/文档修订、证据、公开字段校验与管理身份骨架。
3. M2：整队模板/变体/排障候选 → 人工批准 → 独立发布 → 同一发布版本完整获取；提供不依赖桌面的可重复演示。
4. M3/M4：许可允许的来源Adapter、去重/覆盖报告、版本/环境与冲突；关键词/向量检索；受控即时公共搜索，未审核证据独立标记；三模式内容候选和成本基础资料。
5. M5：完整公共包/manifest、依赖和哈希、兼容能力、撤回/禁用、发布失败与回滚、任务幂等/检查点恢复。
6. M6：本机部署说明、邀请身份/只读默认、更新/审核/发布分权、隔离审计、服务器配置与迁移恢复说明。外部部署资源未提供时明示待部署，不自行购买或猜测凭据。

作者/热度创作模块不作为上述基本管线的前置；不能因尚无指数或模型服务而阻塞可独立完成的工作。保留已有配额和质量规则，不自行调整权重或自动发布门槛。

## 技术验收

- 非允许字段被拒绝，错误和日志不回显私有输入；后端不代理 UID。
- 资料、关卡、模板、完整变体与证据固定于同一发布版本，未知schema/依赖缺失不得拼凑执行。
- 审核未通过不发布；审核通过不自动激活。人工批准不能由模型、fixture或管理员默认值伪造。
- 原文默认最小许可摘录，版本/环境/实装范围和内容覆盖有记录；临时证据不成为正式模板。
- 发布和任务重试幂等，失败保留有效版本，回滚不恢复最新禁用内容。
- 组件自行提供测试和运行入口、合成公共样例及构建/依赖说明；由Goal指令授权后实施并验证。
- 输出给B/C的公共包具有明确版本及兼容声明；未与对方联调的事项明确列出。

## 内容验收的人工关口
