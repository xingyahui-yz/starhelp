# ADR-0018：公开知识后端与本地账号规划分离

状态：Accepted，2026-10-14；替代 ADR-0012 的云端匿名构筑路线。

StarHelp 采用 Windows 桌面、本地账号与规则规划、公开 RAG 知识后端的边界；账号字段及其推导信息即使去掉 UID 也不进入远程模型或知识服务。玩家确认后，UID/区服只由桌面直连选定公开档案服务；首版不采集游戏登录凭据。

为兼顾隐私与攻略可追溯性，首版后端发布人工审核的完整队伍模板、变体和排障规则，桌面执行条件适配而不安装本地大模型，也不自由组合独立替代。代价是推荐覆盖取决于审核模板，缺少适用模板时只提供公共资料和缺口；临时网络证据不成为个性化队伍。

实施时需迁移旧 Provider 的 `account_payload` 接口与账号/执行耦合流程；现有离线模拟和历史 ADR 用作开发记录，不能扩展目标产品的数据或操作权限。接口契约、数据库和客户端均遵守这一决定。
