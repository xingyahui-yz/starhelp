# 初始威胁模型

| 资产 | 威胁 | 当前控制 |
|---|---|---|
| 游戏账号 | 未授权自动输入 | 默认拒绝安全内核、无真实输入后端 |
| 稀缺资源 | 错误页面误操作 | 页面黑名单、语义动作白名单 |
| 登录态 | 凭据泄露 | 不读取账号凭据；只复用官方已有登录态 |
| 账号构筑 | 多账号串用 | `account_id`、不可变 `snapshot_id` 和一致性校验 |
| 战斗方案 | 审查后篡改 | 稳定计划哈希和一次性授权 |
| AI 输出 | 越权动作 | Schema/计划验证；只输出语义规则 |
| 屏幕状态 | OCR/视觉误判 | 置信度门控；未知状态停止 |
| 用户电脑 | 输入发送到其他窗口 | 目标进程与前台焦点检查 |

## 当前残余风险

任何第三方自动化都不能保证不触发账号处罚。当前代码阶段不发送系统输入，因此不会执行战斗；未来引入真实输入前必须重新完成专项威胁建模、官方规则检查和人工验收。
